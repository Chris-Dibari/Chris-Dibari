# ¡Hola! Soy Christian Dibari 👋

Estudiante de Ciencias del Mar apasionado sobre todo por la ingeniería costera, el análisis de datos oceanográficos y la hidráulica ambiental. 
Mi objetivo es especializarme en la gestión, modelado y diseño de obras e infraestructuras del litoral mediante el Máster de Costas y Puertos 
de la Universidad de Cantabria.

# Áreas de Interés 🌊

- 📈 Análisis de series temporales de oleaje, viento y mareas.
- 💻 Modelado numérico de propagación de ondas y morfodinámica de playas.
- 🗺️ Sistemas de Información Geográfica (SIG) aplicados a la gestión costera.
- ⛰️ Gestión de riesgos provocados por eventos extremos.

# 🛠️ Herramientas y Lenguajes (En aprendizaje activo)

- Software/Herramientas: QGIS, GitHub Copilot.
